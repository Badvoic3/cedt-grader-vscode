# Log in

Type your **grader** username and password (the ones you use on the grader website) in the **Account** section.

- **Remember password on this computer**: keeps the password in your operating system's keychain, so the extension logs in again by itself when the grader's 12-hour login expires. Turn it off on a shared computer.
- The password is never written to settings, files or logs. **Log out** deletes it.
- After several wrong passwords the grader blocks logins for a few minutes (website and VS Code count together). Wait, then try once.
