# Optional: Competitive Programming Helper

[Competitive Programming Helper](https://marketplace.visualstudio.com/items?itemName=DivyanshuAgrawal.competitive-programming-helper) (CPH) runs test cases on your own computer.

- With CPH installed, **Load test cases** saves the grader's test cases into CPH ("Saved to CPH"). Your own CPH tests stay first.
- Without CPH, **Load test cases** can save them as `.in` / `.out` files next to your source instead.
- Files with CPH data are matched to their grader problem automatically.

This step is optional; everything else works without CPH.
