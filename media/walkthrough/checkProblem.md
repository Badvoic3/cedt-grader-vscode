# Check the problem

Under **Current problem** you see which grader problem the file belongs to, and a line saying how it was chosen:

- **Matched by file name**: the file is named like the problem (`00_Intro_11.cpp` → `00_Intro_11`; case, spaces, `-`, `_` and `.` don't matter).
- **Suggested from the file name · Use this**: the name is close to one problem. Click **Use this** to keep it.
- **Chosen by you**: you picked it from the list. Your choice is remembered and always wins.

Wrong problem? Click it and choose another one (search by name or id), or press ✕ to stop matching this file.
