# Submit

กด **ส่ง** (หรือปุ่ม ☁ บนแถบชื่อไฟล์ของ editor) แล้วยืนยัน

- **ผลตรวจ** แสดงสถานะระหว่างรอตรวจ แล้วแสดงช่องของแต่ละ test ข้อความจาก compiler ถ้า compile error และบอกว่าคะแนนที่ได้ดีขึ้นหรือไม่
- **คะแนนที่ได้** คือคะแนนจากการส่งที่ดีที่สุด (ไม่ใช่ครั้งล่าสุด) หักคะแนนจาก hint / AI assist แล้ว เหมือนบนเว็บไซต์ คะแนนสุดท้ายที่อาจารย์ให้อาจต่างจากนี้
- **ประวัติการส่ง** แสดงการส่งทุกครั้ง เปิดโค้ดเวอร์ชันเก่าหรือเทียบกับไฟล์ปัจจุบันได้

ถ้าโจทย์ดูเหมือนเป็นส่วนหนึ่งของการสอบ ส่วนขยายจะเตือนก่อน สอบถามอาจารย์ผู้สอนก่อนใช้ในการสอบ
