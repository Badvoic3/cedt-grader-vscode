# เข้าสู่ระบบ

ใส่ชื่อผู้ใช้และรหัสผ่านของ **Grader** (ชุดเดียวกับที่ใช้บนเว็บไซต์ Grader) ในส่วน **บัญชี**

- **จำรหัสผ่านไว้ในเครื่องนี้**: เก็บรหัสผ่านไว้ใน keychain ของระบบปฏิบัติการ เมื่อการเข้าสู่ระบบ Grader หมดอายุ (ทุก 12 ชั่วโมง) ส่วนขยายจะเข้าสู่ระบบใหม่ให้เอง ถ้าใช้เครื่องร่วมกับคนอื่นให้ปิดตัวเลือกนี้
- รหัสผ่านไม่ถูกเขียนลงในการตั้งค่า ไฟล์ หรือ log การ **ออกจากระบบ** จะลบรหัสผ่านที่บันทึกไว้
- ถ้าใส่รหัสผ่านผิดหลายครั้ง Grader จะระงับการเข้าสู่ระบบไว้สักครู่ (นับรวมกันทั้งเว็บไซต์และ VS Code) รอสักพักแล้วลองใหม่ครั้งเดียว
