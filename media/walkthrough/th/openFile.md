# เปิดไฟล์โค้ดคำตอบ

1. ไปที่ **File → Open Folder…** แล้วเลือกโฟลเดอร์ที่เก็บไฟล์คำตอบของคุณ ข้อมูลการเชื่อมระหว่างไฟล์กับโจทย์จะถูกบันทึกไว้ในโฟลเดอร์นี้ (`.cedt-grader.json`)
2. เปิดไฟล์คำตอบ เช่น `00_Intro_11.cpp`

ส่วนขยายจะรู้จักไฟล์ภาษา C, C++, Python และ Java จากนามสกุลไฟล์ (`.c`, `.cpp`, `.py`, `.java`, …) ภาษาอื่นที่ Grader รับก็ใช้ได้เช่นกัน

เคล็ดลับ: ในรายการ **โจทย์ทั้งหมด** คุณสามารถคลิกที่โจทย์เพื่อเปิดไฟล์ของโจทย์นั้น หรือสร้างไฟล์ใหม่ที่ตั้งชื่อตามโจทย์ได้เลย
