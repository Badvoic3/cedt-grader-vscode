# เปิดไฟล์คำตอบ

1. **File → Open Folder…** แล้วเลือกโฟลเดอร์ที่เก็บคำตอบ การเชื่อมไฟล์กับโจทย์จะบันทึกไว้ในโฟลเดอร์นี้ (`.cedt-grader.json`)
2. เปิดไฟล์คำตอบ เช่น `00_Intro_11.cpp`

ไฟล์ C, C++, Python และ Java จะรู้ภาษาจากนามสกุลไฟล์ (`.c`, `.cpp`, `.py`, `.java`, …) ภาษาอื่นที่ Grader รับก็ใช้ได้เหมือนกัน

เคล็ดลับ: ในรายการ **โจทย์** คลิกที่โจทย์เพื่อเปิดไฟล์ของโจทย์นั้น หรือสร้างไฟล์ใหม่ที่ตั้งชื่อตามโจทย์
