# แผง CEDT Grader

คลิกไอคอน **CEDT Grader** ในแถบด้านซ้าย (รูปกระดาษมีเครื่องหมายถูกและลูกศร) ในแผงมี 5 ส่วน:

- **บัญชี**: เข้าสู่ระบบและออกจากระบบ
- **โจทย์ปัจจุบัน**: โจทย์ของไฟล์ที่กำลังแก้ คะแนนที่ได้ ภาษา และปุ่ม **ส่ง**
- **ผลตรวจ**: ผลของแต่ละ test หลัง Submit
- **ประวัติการส่ง**: การส่งทั้งหมดของโจทย์นี้ รวมถึงที่ส่งจากเว็บไซต์
- **โจทย์**: โจทย์ทุกข้อพร้อมคะแนนที่ได้ กรอง ค้นหา และคลิกเพื่อเปิดไฟล์ของโจทย์ได้

**ภาษาของแผง:** แผงแสดงเป็นภาษาอังกฤษโดยค่าเริ่มต้น เปลี่ยนเป็นภาษาไทยได้ที่การตั้งค่า **CEDT Grader: Display Language** (เลือก "ไทย (Thai)" หรือ "ตาม VS Code")

ลากแผงไปไว้ด้านขวาของหน้าต่างได้ถ้าชอบแบบนั้น
