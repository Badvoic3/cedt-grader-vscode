# Open a solution file

1. **File → Open Folder…** and choose the folder with your solutions. Links between files and problems are saved in this folder (`.cedt-grader.json`).
2. Open a solution file, e.g. `00_Intro_11.cpp`.

C, C++, Python and Java files are recognised from their extension (`.c`, `.cpp`, `.py`, `.java`, …). Other languages the grader accepts work too.

Tip: in the **Problems** list, click a problem to open its file, or create a new one named after the problem.
